NEWTheme Commerce - WordPress/WooCommerce Theme
============================================

INSTALL:
1. WordPress Admin > Appearance > Themes > Add New > Upload Theme.
2. Upload newtheme.zip, install and activate.
3. Install/activate WooCommerce. Use its setup wizard to create Shop, Cart, Checkout and My Account pages.
4. Add product categories and products via Products in WP Admin.
5. Appearance > Customize > Homepage Hero: edit hero title, subtitle, button, image URL.
6. Set the homepage in Settings > Reading if required; the front-page.php template is used for the site front page.
7. Create About, Contact, FAQ, Returns, Terms, Privacy, and Blog pages as needed.
8. Configure payment gateway, shipping, taxes, email, privacy, backups, and security before launch.

FEATURES/INTEGRATION:
- Modular CSS split into components (navbar, footer, home, shop, product, forms, account, responsive)
- Modular JavaScript
- Bootstrap 5.3 and Bootstrap Icons via CDN
- WooCommerce theme support: product listing/details, cart, checkout, customer accounts, orders, coupons, inventory, payments, shipping, reviews and analytics are managed by WooCommerce and its plugins/admin interface.
- Homepage: hero, trust benefits, categories, popular products, promotional banner, new products, newsletter demo.
- Responsive layouts.

WISHLIST / TRACKING:
These are not native WooCommerce core features. Install and configure a reputable wishlist plugin and shipment/order-tracking extension as needed. The theme includes links/space to add them but does not implement vendor-specific integrations.

SECURITY / PRODUCTION:
- Use HTTPS and trusted hosting.
- Keep WordPress, plugins and themes updated.
- Do not install nulled plugins.
- Configure backups, anti-spam, security, payment provider and privacy policy.
- Test checkout and transactional emails in staging before accepting real orders.

NOTES:
The theme uses remote sample images. Replace image URLs in template-parts/sections/categories.php, promo.php and customize the hero image.
